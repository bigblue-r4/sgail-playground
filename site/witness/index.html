The log

Why it's caught

Every entry is hashed, pairs of hashes are hashed together, up to one root. The witness signs that root. Change any entry and every hash above it changes too (red), so the root no longer matches.

What runs. The witness from kiss-protocol v3.3.3, compiled for the browser. The Merkle tree is its own code, unchanged. The head check and the mirror audit are its store and audit code with only the file reading and writing taken out, and a test runs them against the real store to prove they give the same verdicts.

What it isn't. It detects and records. It can't stop anyone and it doesn't control the house. The head is signed on the same machine, so someone with full control of that machine can re-sign a rewritten log, and the local check passes. A copy of the head kept somewhere else (the mirror) is what catches that, so the mirror belongs on a different machine. The real log is also encrypted on disk; that part isn't shown here. The keys on this page are made fresh in your browser.
